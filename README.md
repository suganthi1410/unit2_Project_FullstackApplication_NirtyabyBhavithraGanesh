<a name="about"></a>
## 💡 About the Project

I created this full‑stack project as part of my journey to strengthen my skills in modern web development. My goal was to build a complete application from scratch — something meaningful, structured, and visually engaging — while practicing real‑world concepts in both React and Java Spring Boot.
The frontend is built with React, focusing on clean UI design, accessibility, and responsive layouts. The backend uses Java Spring Boot and MySQL to handle all data storage and retrieval. Since my focus was on mastering CRUD operations, routing, database relationships, and API integration.

The main branch contains the advanced version of the project that I continue to refine as part of my personal portfolio. It reflects my growth as a developer and demonstrates my ability to design, structure, and maintain a full‑stack application end‑to‑end. Other branches contain earlier versions created while learning and experimenting with different features.

<a name="features"></a>
## ✨ Features

### Core User Features
- View detailed class timings
- Read about the dance school’s background and mission
- Learn about the teacher and her dance journey
- Explore a dedicated review page
- Submit, edit, and delete reviews (after login)

### Frontend Features
- Fully responsive UI built with React + Vite
- Clean layout with modern typography and icons
- Smooth navigation using React Router
- Form validation for review submission
- Gallery page with organized photo display
- Contact page with structured form fields

### Backend Features
- REST API built using Spring Boot
- MySQL database with Level ↔ Review one‑to‑many relationship
- Predefined user login for review access
- CRUD operations for reviews
- Admin‑only endpoints for level creation
- Hibernate ORM for automatic table creation

### Database Features
- Two main entities: Levels and Reviews
- One‑to‑many relationship
- Auto‑generated IDs
- Clean separation of concerns
- Easy future expansion for Events, Announcements, and Class Schedules

### Authentication (Simplified)
- Predefined user stored in database
- Basic username/password validation
- No JWT or Spring Security

<a name="installation"></a>
## 🚀 Prerequisites & Installation

### Back End Setup (Java/Spring Boot/MySQL)

1.  **Clone the repository:** In the terminal, navigate to the directory where you want the project to live, then execute the following commands:
    ```shell
    git clone https://github.com/suganthi1410/unit2_Project_FullstackApplication_NirtyabyBhavithraGanesh.git  
    ```

1.  **Configure secrets for database, Create a new MySQL database named `unit2_finalproject_backend`, : 
    ```properties
    # Location of your local database server
    DB_HOST=localhost
    DB_PORT=3306
    
    # Database name
    DB_NAME=unit2_finalproject_backend
    
    # Credentials
    DB_USER=root
    DB_PASS=[your_password]   

    ```
1.  **Run the Java/Spring Boot application:** If you do not have the application loaded in an IDE such as IntelliJ, go to the terminal and navigate to the root directory of the backend project. Then execute the following command to build and run the application (Hibernate will automatically create the tables): 
    ```shell
    mvn spring-boot:run
    ```
    
    🟢 The API should now be running on `http://localhost:8080`.

### Front End Setup (React/Vite)

1.  **Navigate to the front end project directory:** 
    ```shell
    cd ../frontend
    ```

1.  **Install dependencies:** 
    ```shell
    npm install
    ```

1.  **Run the React/Vite application:** 
    ```shell
    npm run dev   
    
    🟢 The frontend application will start and can be found in a browser, typically at `http://localhost:5173`.

<a name="api"></a>
## ⚙️ API Endpoints

The following RESTful endpoints manage data access. 
### Levels 
| HTTP Method | Endpoint | Description | Access |
| :--- | :--- | :--- | :--- |
| 🟢 `GET` | `/levels` | Retrieve all levels in database | 🔰 Admin |
| 🟡 `POST` | `/levels` | levels created in database by admin | 🔰 Admin |


### Reviews
| HTTP Method | Endpoint | Description | Access |
| :--- | :--- | :--- | :--- |
| 🟢 `GET` | `/reviews` | Retrieve all reviews | 🌎 Public |
| 🟢 `GET` | `/reviews/level/:levelId` | Retrieve levels by level id | 🔰 Admin |
| 🟢 `GET` | `/reviews/:id` | Retrieve levels by id | 🌎 Public |
| 🟡 `POST` | `/reviews/post` | User creates a new review | 🌎 Public |
| 🟠 `PATCH` | `/reviews/update/:id` | User can update review | 🌎 Public |
| 🔴 `DEL` | `/reviews/:id` | User can delete review | 🌎 Public |

### User
| HTTP Method | Endpoint | Description | Access |
| :--- | :--- | :--- | :--- |
🟡 `POST` | `/login` | Validate username and password against predefined user stored in the database | 🌎 Public |
